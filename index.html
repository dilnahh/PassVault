Core Concept

How Login Verification Works

Plaintext passwords are never compared or stored.

1
User Inputs Password Plaintext string entered into the login field
↓
2
SHA-256 Hashing Web Crypto API generates a 256-bit (64 hex char) digest
↓
3
Compare Hashes Candidate hash is compared to stored hash in localStorage
↓
4
Match = Authenticated If hashes match exactly, access is granted!
💡 Irreversible One-Way Function Hashing is a strictly one-way process. Even if an attacker inspects localStorage, they only obtain the hash. The original password cannot be mathematically reversed.
